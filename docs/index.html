NASA Inspired Rover Work in Progress

An open source, 3D printable 6-wheel rocker-bogie rover inspired by NASA’s Perseverance. All printable parts are available as 3MF files. This project is actively being developed — parts, docs, and sections will be added as the build progresses.

⬇ View on GitHub
🚧 Work in Progress This rover is actively being designed and built. Parts, documentation, and sections will be added and updated as the build progresses. Some parts may be duplicates or subject to change once physical prints are verified.
